*Заметки
Система рейтингов Эло, коэффициент Эло — метод расчёта относительной силы игроков в играх, в которых участвуют двое игроков
Классический пример работы рейтинга Эло
Шанс хозяев по рейтингам: E = 1 / (1 + 10^((R_гостей − (R_хозяев + 100)) / 400))
Фактический результат S: победа хозяев 1, ничья 0,5, победа гостей 0.
Изменение: дельта = 20 × (S − E)
Новые рейтинги: хозяева + дельта, гости − дельта.
Все команды стартуют с рейтингом 1500. 100 это домашний бонус, он входит только в формулу E, сами рейтинги он не меняет
