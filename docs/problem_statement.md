# Постановка задачи

## Что предсказываем
Мы предсказываем исход матча чемпионата Испании по футболу (Ла Лига) до его начала. Это задача классификации на три класса: победа хозяев (H), ничья (D) и победа гостей (A). Кроме класса, модель выдаёт вероятности трёх исходов, которые в сумме дают единицу.

## Данные и разбиение
Используются результаты матчей Ла Лиги за 12 завершённых сезонов, с 2014/15 по 2025/26 (4560 матчей, по 380 в сезоне). Данные делятся не случайно, а по времени, потому что при перемешивании в обучение попали бы матчи из будущего относительно проверочных, и оценка получилась бы завышенной (утечка данных).

- Обучение: сезоны 2014/15-2022/23 (3420 матчей).
- Проверка (валидация): сезон 2023/24 (380 матчей). На нём сравниваем признаки и модели.
- Тест: сезоны 2024/25 и 2025/26 (760 матчей). Открываем один раз, в конце, для итоговой оценки.

Все признаки матча (рейтинг Эло, форма команд) считаются только по матчам, сыгранным до него.

## Метрики
- Log loss (основная метрика). Оценивает качество вероятностей, а не только угаданный класс. Чем меньше, тем лучше. Для угадывания по 1/3 он равен примерно 1,10.
- Accuracy: доля верных прогнозов. Понятна, но не показывает, какие исходы модель путает.
- Macro-F1: среднее качество по трём классам, не даёт редкой ничьей потеряться.
- Матрица ошибок: показывает, какие исходы модель путает между собой.

## С чем сравниваем
Простая стратегия «всегда победа хозяев» даёт accuracy около 0,46 (хозяева выигрывают примерно 44-47% матчей). Модель считается полезной, если она лучше этой стратегии по всем метрикам.
