Заметки про Эло и форму
Вычисляется ожидаемое количество очков, которое получит игрок 
Шанс хозяев по рейтингам: E = 1 / (1 + 10^((R_гостей − (R_хозяев + 100)) / 400))
Фактический результат S: победа хозяев 1, ничья 0,5, победа гостей 0.
Изменение: дельта = 20 × (S − E)
Новые рейтинги: хозяева + дельта, гости − дельта.
Дополнительно (Все команды стартуют с рейтингом 1500. 100 это домашний бонус, он входит только в формулу E, сами рейтинги он не меняет.)

## Форма
- Форма — среднее число очков (победа 3, ничья 1, поражение 0) за последние 5 матчей команды.
- shift(1) сдвигает ряд на один матч, чтобы в форму не попал результат самого матча. Без него это утечка данных.
- Первые три значения пустые (NaN): rolling(5, min_periods=3) требует минимум 3 предыдущих матча.
- Пример: для 4-го матча форма = среднее (3, 1, 0) = 1,333.
- Пустые значения не удаляем, их заполнит конвейер модели позже.
