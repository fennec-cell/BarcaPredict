# Метрики

Почему нельзя перемешивать данные: 

1. Матч предсказывают по прошлому.
2. Если перемешать строки, в обучении окажутся матчи из будущего относительно проверочных, и результат будет лучше, чем в жизни. Это утечка данных.
3. Поэтому делим по сезонам: обучение 2014/15–2022/23, проверка 2023/24, тест 2024/25 и 2025/26 (тест открываем один раз).
4. Пример: как готовиться к экзамену по заданиям, ответы к которым уже видели.

# Метрики качества

Мы предсказываем исход матча: H (победа хозяев), D (ничья), A (победа гостей).
Это задача классификации на три класса.

## Accuracy (доля верных прогнозов)
- Что это: сколько прогнозов из всех оказались верными.
- Как считается: число верных прогнозов / число всех матчей.
- Пример: настоящие исходы H, D, A, H, прогноз H, H, A, D. Верных 2 из 4, accuracy = 0,5.
- Плюс: просто понять.
- Минус: не видит, какие исходы модель путает. Если всегда говорить H,
  получится около 0,46, хотя ничьи не угадываются никогда.
- Что значит «хорошо»: выше, чем у простой стратегии «всегда H».

## Macro-F1
- Что это: качество по каждому из трёх исходов отдельно, потом среднее.
- Precision: какая доля прогнозов «H» верна.
- Recall: какую долю настоящих «H» модель нашла.
- F1: объединяет precision и recall в одно число для одного класса.
- Macro: берём F1 для H, D, A и усредняем, чтобы редкая ничья не терялась.
- Пример (тот же): F1(H)=0,5, F1(D)=0, F1(A)=1, среднее 0,5.
- Что значит «хорошо»: чем ближе к 1, тем лучше; значение около 0,21
  означает «модель ничего не умеет» (она всегда говорит H).

## Log loss (логарифмическая потеря)
- Что это: насколько хороши сами вероятности, а не только угадала ли модель.
- Как считается: берём вероятность, которую модель дала правильному исходу,
  считаем минус натуральный логарифм, усредняем по матчам.
- Пример: вероятности правильных исходов 0,5; 0,2; 0,6; 0,4.
  -ln: 0,69; 1,61; 0,51; 0,92. Среднее 0,93.
- Чем меньше, тем лучше.
- Ориентир: если для трёх исходов всегда давать по 1/3, log loss = ln 3 ≈ 1,10.
  Хорошая модель для футбола даёт около 1,0.

## Матрица ошибок
- Таблица 3x3: строки настоящий исход, столбцы прогноз.
- На диагонали верные ответы.
- Как читать: клетка «строка D, столбец H» это матчи, где была ничья,
  а модель сказала победу хозяев.

## Какую метрику мы используем
- Для выбора лучшей модели: log loss.
- В отчёте показываем все три метрики и матрицу ошибок.

## Baseline «всегда H»
- Стратегия: для каждого матча предсказываем победу хозяев; вероятности берём из долей исходов в обучающих сезонах.
- Тест: сезоны 2023/24, 2024/25, 2025/26 (1140 матчей).
- Accuracy: 0,458
- Macro-F1: 0,209
- Log loss: 1,065
- Матрица ошибок: все 1140 прогнозов в столбце H (321 гостевая победа, 297 ничьих и 522 домашние победы угаданы или нет, только H верно).
- Любая модель с признаками должна быть лучше: accuracy выше 0,458, macro-F1 выше 0,209, log loss ниже 1,065.

## Модель: Elo + логистическая регрессия
- Признак: elo_diff (рейтинг хозяев минус рейтинг гостей, считается до матча, у всех команд старт 1500, бонус дома 100, K=20).
- Модель: логистическая регрессия (scikit-learn).
- Обучение: сезоны 2014/15-2022/23. Тест: 2023/24, 2024/25, 2025/26 (1140 матчей).

| Метрика | Baseline «всегда H» | Elo + логрегрессия |
|---|---|---|
| Accuracy | 0,458 | 0,532 |
| Macro-F1 | 0,209 | 0,389 |
| Log loss | 1,065 | 0,972 |

Матрица ошибок (строки: настоящий исход A, D, H; столбцы: прогноз A, D, H):
- A: 167, 0, 154
- D: 102, 0, 195
- H: 83, 0, 439

Выводы:
- Один признак elo_diff улучшил все три метрики по сравнению с baseline.
- Ничьи (D) модель не предсказывает ни разу: вероятность ничьей почти всегда ниже вероятности победы одной из команд. Поэтому macro-F1 остаётся невысоким.
- Дальше: добавить форму за 5 матчей и разницу голов, подбирать на валидации (2023/24), тест открыть один раз в конце.

## Результаты на валидации (сезон 2023/24, 380 матчей)
Признаки и модель подбираем на этом сезоне. Тест (2024/25 и 2025/26) пока не открывали.

### Elo (elo_diff) + логистическая регрессия
- Accuracy: 0,516
- Macro-F1: 0,385
- Log loss: 0,961

Матрица ошибок (строки: настоящий исход A, D, H; столбцы: прогноз A, D, H):
- A: 58, 0, 48
- D: 41, 0, 66
- H: 29, 0, 138

Выводы:
- На валидации модель с признаком elo_diff лучше простой стратегии «всегда H»: в этом сезоне хозяева выиграли 167 матчей из 380, то есть «всегда H» даёт accuracy около 0,44.
- Ничьи (D) модель не предсказывает ни разу: столбец D состоит из нулей.

### Сравнение наборов признаков на валидации (2023/24)

| Набор признаков | Accuracy | Macro-F1 | Log loss |
|---|---|---|---|
| elo_diff | 0,516 | 0,385 | 0,961 |
| elo_diff + form_diff | 0,516 | 0,385 | 0,960 |
| elo_diff + form_diff + gd_diff | 0,526 | 0,390 | 0,961 |

Вывод: форма за 5 матчей и разница голов почти не улучшают модель (разница в log loss 0,001, это в пределах шума на 380 матчах). Elo уже учитывает последние результаты команд.


### Сравнение моделей на валидации (2023/24)
Признаки: elo_diff, form_diff, gd_diff, h_elo, a_elo.

| Модель | Accuracy | Macro-F1 | Log loss |
|---|---|---|---|
| Логистическая регрессия (со StandardScaler) | 0,526 | 0,391 | 0,959 |
| Случайный лес (300 деревьев, глубина 4) | 0,534 | 0,398 | 0,968 |
| Градиентный бустинг (глубина 3) | 0,518 | 0,406 | 0,981 |

Вывод: по главной метрике (log loss) лучшая модель это логистическая регрессия. Более сложные модели не дали выигрыша: разница в accuracy составляет несколько матчей из 380 и находится в пределах шума. Поэтому для финальной оценки берём логистическую регрессию.


## Итог на тесте (сезоны 2024/25 и 2025/26, 760 матчей)
Модель: логистическая регрессия со StandardScaler. Признаки: elo_diff, form_diff, gd_diff, h_elo, a_elo. Обучение на сезонах 2014/15-2023/24. Тест открыт один раз.

| | Accuracy | Macro-F1 | Log loss |
|---|---|---|---|
| Baseline «всегда H» | 0,467 | 0,212 | 1,060 |
| Логистическая регрессия | 0,538 | 0,389 | 0,976 |

Матрица ошибок модели (строки: настоящий исход A, D, H; столбцы: прогноз A, D, H):
- A: 108, 0, 107
- D: 63, 0, 127
- H: 54, 0, 301

Выводы:
- Модель лучше baseline по всем метрикам: accuracy выше на 7 процентных пунктов, log loss ниже на 0,08.
- Результат на тесте близок к результату на валидации, переобучения нет.
- Ничьи (D) модель не предсказывает ни разу, это ограничение подхода: вероятность ничьей почти никогда не бывает самой высокой.
- Победы хозяев (H) модель находит лучше всего (301 из 482 прогнозов H верны).


## Доли исходов по выборкам

| Выборка | Матчей | Победа хозяев (H) | Ничья (D) | Победа гостей (A) |
|---|---|---|---|---|
| Обучение (2014/15-2022/23) | 3420 | 0,456 | 0,258 | 0,286 |
| Валидация (2023/24) | 380 | 0,439 | 0,282 | 0,279 |
| Тест (2024/25, 2025/26) | 760 | 0,467 | 0,250 | 0,283 |

Вывод: победы хозяев составляют около 44-47% матчей во всех трёх выборках. Это и есть простая стратегия «всегда H», которую модель должна превзойти (на тесте её accuracy равна доле H, то есть 0,467). Доли исходов в выборках близки, значит, разбиение по сезонам не создаёт заметного перекоса.

### Обработка пропусков
У первых матчей команды в сезоне 2014/15 нет истории, поэтому форма и разница голов пустые. Пропуски заполняет SimpleImputer(strategy='median') внутри конвейера: медиана считается только по обучающим данным, поэтому утечки нет.

Результат на валидации (2023/24): accuracy 0,526, macro-F1 0,391, log loss 0,960. Он почти не отличается от варианта с заменой пропусков нулём (log loss 0,959), так что пропусков мало и на качество они не влияют.


### Базовая стратегия по разнице Elo
Правило: если рейтинг хозяев с бонусом дома (elo_diff + 100) больше нуля, предсказываем победу хозяев (H), иначе победу гостей (A). Ничьи не предсказываются, вероятностей правило не выдаёт, поэтому log loss для него не считается.

Результат на валидации (2023/24): accuracy 0,521, macro-F1 0,384.

Матрица ошибок (строки: настоящий исход A, D, H; столбцы: прогноз A, D, H):
- A: 51, 0, 55
- D: 31, 0, 76
- H: 20, 0, 147

Вывод: простое правило по Elo почти не уступает логистической регрессии (accuracy 0,526, macro-F1 0,391). Основной вклад в качество даёт рейтинг Elo, остальные признаки добавляют мало.
