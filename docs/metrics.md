# Метрики

Почему нельзя перемешивать данные: 

1. Матч предсказывают по прошлому.
2. Если перемешать строки, в обучении окажутся матчи из будущего относительно проверочных, и результат будет лучше, чем в жизни. Это утечка данных.
3. Поэтому делим по сезонам: обучение 2014/15–2022/23, проверка 2023/24, тест 2024/25 и 2025/26 (тест открываем один раз).
4. Пример: как готовиться к экзамену по заданиям, ответы к которым уже видели.

# Метрики качества

Мы предсказываем исход матча: H (победа хозяев), D (ничья), A (победа гостей).
Это задача классификации на три класса.

## Accuracy (доля верных прогнозов)
- Что это: сколько прогнозов из всех оказались верными.
- Как считается: число верных прогнозов / число всех матчей.
- Пример: настоящие исходы H, D, A, H, прогноз H, H, A, D. Верных 2 из 4, accuracy = 0,5.
- Плюс: просто понять.
- Минус: не видит, какие исходы модель путает. Если всегда говорить H,
  получится около 0,46, хотя ничьи не угадываются никогда.
- Что значит «хорошо»: выше, чем у простой стратегии «всегда H».

## Macro-F1
- Что это: качество по каждому из трёх исходов отдельно, потом среднее.
- Precision: какая доля прогнозов «H» верна.
- Recall: какую долю настоящих «H» модель нашла.
- F1: объединяет precision и recall в одно число для одного класса.
- Macro: берём F1 для H, D, A и усредняем, чтобы редкая ничья не терялась.
- Пример (тот же): F1(H)=0,5, F1(D)=0, F1(A)=1, среднее 0,5.
- Что значит «хорошо»: чем ближе к 1, тем лучше; значение около 0,21
  означает «модель ничего не умеет» (она всегда говорит H).

## Log loss (логарифмическая потеря)
- Что это: насколько хороши сами вероятности, а не только угадала ли модель.
- Как считается: берём вероятность, которую модель дала правильному исходу,
  считаем минус натуральный логарифм, усредняем по матчам.
- Пример: вероятности правильных исходов 0,5; 0,2; 0,6; 0,4.
  -ln: 0,69; 1,61; 0,51; 0,92. Среднее 0,93.
- Чем меньше, тем лучше.
- Ориентир: если для трёх исходов всегда давать по 1/3, log loss = ln 3 ≈ 1,10.
  Хорошая модель для футбола даёт около 1,0.

## Матрица ошибок
- Таблица 3x3: строки настоящий исход, столбцы прогноз.
- На диагонали верные ответы.
- Как читать: клетка «строка D, столбец H» это матчи, где была ничья,
  а модель сказала победу хозяев.

## Какую метрику мы используем
- Для выбора лучшей модели: log loss.
- В отчёте показываем все три метрики и матрицу ошибок.

## Baseline «всегда H»
- Стратегия: для каждого матча предсказываем победу хозяев; вероятности берём из долей исходов в обучающих сезонах.
- Тест: сезоны 2023/24, 2024/25, 2025/26 (1140 матчей).
- Accuracy: 0,458
- Macro-F1: 0,209
- Log loss: 1,065
- Матрица ошибок: все 1140 прогнозов в столбце H (321 гостевая победа, 297 ничьих и 522 домашние победы угаданы или нет, только H верно).
- Любая модель с признаками должна быть лучше: accuracy выше 0,458, macro-F1 выше 0,209, log loss ниже 1,065.
